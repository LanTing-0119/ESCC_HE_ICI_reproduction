# Data contract

`clinical_example.csv` contains **one fabricated patient**, with no relationship to the TCGA slides. It is a schema example, not a dataset for statistical inference. `slide_manifest_example.csv` shows the join contract; it does not point to a real slide.

| Field | Meaning |
|---|---|
| patient_id | Unique string across cohorts; use anonymized research identifiers |
| cohort | JUPITER06 (development) or ESCORT1ST (external) |
| treatment | 1 = ICI+CT; 0 = CT |
| image_included | 1 = included in image analysis; 0 = trial patient without study images |
| age | Years; blank if unavailable |
| sex | Male / Female; blank if unavailable |
| ECOG | Performance status; blank if unavailable |
| TPS | PD-L1 tumor proportion score, 0–100%; blank if missing |
| best_response | CR, PR, SD, PD, NE, Non-CR/Non-PD, or Missing |
| PFS_time, OS_time | Positive follow-up time in months |
| PFS_event, OS_event | 1 = event; 0 = censored |

Scores, B/NB assignments and fold numbers are generated by the analysis. Do not put them into the clinical input. All randomized patients are required for Tables S2–S3; feature manifests contain only image-included patients. No automatic imputation is performed. Missing baseline variables are reported and excluded from their respective tests. Event/time/treatment fields must be complete.

The slide manifest has patient_id, slide_id, wsi_path, feature_path, n_patches. Each slide belongs to exactly one patient. Each feature HDF5 contains a finite, nonzero `features` array of shape `(n_patches, 1536)`. Coordinate HDF5 files use the TRIDENT contract (level-0 x/y coordinates and patch geometry attributes). Multiple slides are averaged equally after slide-level pseudocount smoothing.

## Public WSI example

`tcga_wsi/manifest.csv` documents three open TCGA-ESCA diagnostic slides with GDC squamous-cell-carcinoma diagnoses. The files are included in the full local/server project. Download URLs are supplied for anyone using a code-only copy. Access and diagnosis were checked against GDC file metadata on 8 October 2026. Standard TCGA barcodes map slides to cases; only public identifiers are present.

These slides demonstrate segmentation and feature extraction. They are **not** substitutes for the trial cohorts. Their clinical outcomes are neither used nor fabricated. The optional synthetic clinical/feature demonstration is a separate experiment.

The Cancer Genome Atlas Research Network and NCI GDC are the source of these images. See https://www.cancer.gov/tcga and https://gdc.cancer.gov/access-data/data-access-policies for attribution and current data-use policies. GDC source pages and direct download links are in the manifest.

## Restricted study data

The public package excludes trial clinical records, patient-level predictions, private images, and paper-trained PCA/cluster/Cox parameters. Apply to the respective trial data custodians and study authors under the applicable ethics approval and data-use agreement. No public access is promised. Obtain UNI-v2 weights through the official https://huggingface.co/MahmoodLab/UNI2-h authorization process; no weights or credentials are distributed here.
